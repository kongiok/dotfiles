# Dotfiles

> a place I put my configs and setups

# Install

You could simply install files and dotfiles by using this command:

```sh
sh -c "$(curl -fsSL https://chezmoi.io/get)" -- init --apply kongiok/dotfiles
```

# Acknowledgements

Most of this setup would not exist — or would exist in a far more chaotic,
embarrassing form — without [holman/dotfiles](https://github.com/holman/dotfiles/).
I borrowed heavily from its structure, philosophy, and elegance,
because writing dotfiles from scratch is a great way to feel like you're doing something important while achieving very little.
